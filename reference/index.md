# Package index

## Main Functions

- [`HiClimR()`](https://hsbadr.github.io/HiClimR/reference/HiClimR.md) :
  Hierarchical Climate Regionalization
- [`HiClimR2nc()`](https://hsbadr.github.io/HiClimR/reference/HiClimR2nc.md)
  : Export NetCDF-4 file for Hierarchical Climate Regionalization
- [`validClimR()`](https://hsbadr.github.io/HiClimR/reference/validClimR.md)
  : Validation of Hierarchical Climate Regionalization

## Helper Functions

- [`coarseR()`](https://hsbadr.github.io/HiClimR/reference/coarseR.md) :
  Coarsening spatial resolution for gridded data
- [`fastCor()`](https://hsbadr.github.io/HiClimR/reference/fastCor.md) :
  Fast correlation for large matrices
- [`geogMask()`](https://hsbadr.github.io/HiClimR/reference/geogMask.md)
  : Geographic mask from longitude and latitude
- [`grid2D()`](https://hsbadr.github.io/HiClimR/reference/grid2D.md) :
  Generate longitude and latitude grid matrices
- [`minSigCor()`](https://hsbadr.github.io/HiClimR/reference/minSigCor.md)
  : Minimum significant correlation for a sample size

## Data Sets

- [`TestCase`](https://hsbadr.github.io/HiClimR/reference/TestCase.md) :

  Test Data for Functionality Demonstration of `HiClimR` Package

- [`WorldMask`](https://hsbadr.github.io/HiClimR/reference/WorldMask.md)
  : World Mask for Geographic Masking in HiClimR
